Purpose: TDD discipline — implementation in Plan 02 makes these tests pass.

Critical synchronization note: FastAPI BackgroundTasks run as part of the ASGI response lifecycle.
ASGITransport waits for the ASGI scope to close before returning from `await client.post(...)`.
Starlette closes the scope AFTER executing all background tasks. Therefore, when a test calls
`await client.post("/workflows/{name}/runs", ...)`, the background executor has ALREADY
completed before the response object is returned to the test. No sleep() or polling required.

Critical respx note: Use `async with respx.mock:` context manager (not `@respx.mock` decorator)
so the mock is explicitly active during the ASGI call (including BackgroundTasks). The decorator
pattern has subtler lifecycle boundaries; the context manager is explicit and unambiguous.
</objective>
