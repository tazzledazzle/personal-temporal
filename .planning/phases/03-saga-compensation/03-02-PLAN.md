    Method `async def compensate(self, run) -> None`:

    1. Query COMPLETED step executions for run.id ordered by completed_at DESC. Use
       `select(WorkflowStepExecution).where(WorkflowStepExecution.run_id == run.id,
       WorkflowStepExecution.status == "COMPLETED").order_by(WorkflowStepExecution.completed_at.desc())`.
       Materialize with `(await self.session.execute(stmt)).scalars().all()`.
       Rationale: LIFO by completion time matches test_compensation_lifo_order expectations
       (comp-b before comp-a). Do NOT order by step_index — the test explicitly fixes
       completion order.

    2. For each step_exec in that list:
       a. Look up the matching WorkflowStep via
          `select(WorkflowStep).where(WorkflowStep.workflow_def_id == run.workflow_def_id,
          WorkflowStep.step_order == step_exec.step_index)` (verify the Run model attribute
          name — may be `workflow_def_id` or `workflow_id`; use what Run model exposes).
       b. If the resulting WorkflowStep is None OR its compensate_url is None/empty: skip
          (do not touch compensation_status; leave it NULL).
       c. Otherwise, POST to the compensate_url with a short timeout (reuse the executor's
          timeout convention — check executor.py; if unclear, use 30s). Wrap the call in
          try/except capturing both non-2xx responses and httpx.HTTPError/TimeoutException:
            - On 2xx: set `step_exec.compensation_status = "COMPLETED"`,
              `step_exec.compensated_at = datetime.utcnow()`,
              `step_exec.compensation_error = None`.
            - On non-2xx: set `compensation_status = "FAILED"`,
              `compensation_error = f"HTTP {response.status_code}"`,
              `compensated_at = None` (or leave as-is).
            - On exception: set `compensation_status = "FAILED"`,
              `compensation_error = str(exc)[:500]` (truncate to avoid pathological payloads).
       d. Persist per-step: `async with _write_lock: await self.session.commit()`. Committing
          per step matches the executor's pattern and lets a partial failure be visible even
          if the coordinator later crashes.
       e. NEVER raise or break out of the loop on compensation failure — the whole point of
          the chain is continue-on-failure (COMP-01). Catch broadly inside the per-step block.

    3. After the loop: re-query the step executions (or inspect the locally-updated list) to
       determine the aggregate outcome. Any step whose `compensation_status == "FAILED"`
       flips the run to COMPENSATION_FAILED; otherwise COMPENSATED.
         - `run.status = "COMPENSATION_FAILED" if any(se.compensation_status == "FAILED" for se in step_execs) else "COMPENSATED"`
         - `run.completed_at = datetime.utcnow()`
         - `async with _write_lock: await self.session.commit()`
