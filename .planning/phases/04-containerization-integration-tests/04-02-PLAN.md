<feature>
  <name>Full register → execute → compensate integration test</name>
  <files>tests/test_integration.py</files>
  <behavior>
    The integration test suite exercises three behavioral truths against a real SQLite
    temp file (not in-memory, not ASGITransport):

    Truth 1 — Happy path: register a workflow with two steps (both with compensate_url),
    execute it with both steps mocked to return 200, assert run status == "COMPLETED",
    assert both step statuses == "COMPLETED".

    Truth 2 — Compensation triggered: register a workflow with two steps (step-1 succeeds,
    step-2 fails with 500), assert run status == "COMPENSATED" or "COMPENSATION_FAILED",
    assert step-1 has compensation_status set (compensate_url was called),
    assert step-2 has status == "FAILED".

    Truth 3 — Step timeout triggers compensation: register a workflow with two steps
    (step-1 succeeds, step-2 raises httpx.TimeoutException), assert run status is a
    terminal compensation state, assert step-1 compensation_status is not None.

    These three truths map to Phase 4 success criterion 3.
  </behavior>
  <implementation>
    The tests use:
    - A real NamedTemporaryFile SQLite engine with NullPool + WAL PRAGMAs (same as conftest.py)
    - httpx.AsyncClient with ASGITransport(app=app) for API calls (this is the integration layer;
      the distinction from conftest.py is that the integration tests verify the full stack
      including compensation, not individual units)
    - respx to mock outbound step HTTP calls (execute_url and compensate_url)
    - asyncio.sleep polling loop (max 2 seconds, 10 iterations) to wait for background
      executor task to complete before asserting terminal state

    The test module MUST define its own fixtures (not rely on conftest.py fixtures) to be
    self-contained. Define a module-level `integration_engine` fixture that creates a
    NamedTemporaryFile SQLite DB, runs Base.metadata.create_all, yields the engine, and
    cleans up. Define an `integration_client` fixture that overrides get_db and
    executor_module.AsyncSessionLocal, then yields an httpx.AsyncClient.

    API_KEY for tests: patch settings via monkeypatching or set env var to "integration-test-key"
    before creating the client. Use override_settings approach: after creating the engine and
    before yielding client, call `get_settings.cache_clear()` if needed, or set environment
    variable `API_KEY=integration-test-key` in the test environment and use that header.

    The simplest approach: define `INT_API_KEY = "integration-test-key"` at module level,
    set `os.environ["API_KEY"] = INT_API_KEY` at module level (before any app imports), and
    clear `get_settings.cache_clear()` in the fixture setup.

    For respx mock patterns, use `respx.mock(assert_all_called=False)` as a context manager
    wrapping the execute POST and the polling loop.
  </implementation>
</feature>

  <action>
    Write tests/test_integration.py with the following structure:

    1. Module-level setup:
       - `import os; os.environ.setdefault("API_KEY", "integration-test-key")` BEFORE any app import
       - Import standard libraries: asyncio, os, tempfile
       - Import pytest, respx
       - Import httpx (ASGITransport, AsyncClient)
       - Import sqlalchemy event, async_sessionmaker, create_async_engine, NullPool
       - Import from app.core.database: Base, get_db
       - Import from app.core.config: get_settings
       - Import from app.main: app
       - Import app.runs.executor as executor_module

    2. Constants:
       - `INT_API_KEY = "integration-test-key"`
       - `TERMINAL_STATES = {"COMPLETED", "FAILED", "COMPENSATED", "COMPENSATION_FAILED"}`

    3. Fixture `integration_engine` (scope="function", async):
       - Create NamedTemporaryFile(suffix=".db", delete=False), close it, record path
       - Build db_url = f"sqlite+aiosqlite:///{tmp.name}"
       - Create engine with create_async_engine(db_url, connect_args={"check_same_thread": False}, poolclass=NullPool)
       - Register WAL PRAGMAs via @event.listens_for(engine.sync_engine, "connect")
         setting: PRAGMA journal_mode=WAL; PRAGMA busy_timeout=5000; PRAGMA synchronous=NORMAL; PRAGMA foreign_keys=ON;
       - async with engine.begin() as conn: await conn.run_sync(Base.metadata.create_all)
       - yield engine
       - await engine.dispose()
       - os.unlink(tmp.name)

    4. Fixture `integration_client` (scope="function", async) depends on `integration_engine`:
       - get_settings.cache_clear()  # force re-read with INT_API_KEY
       - Create TestSession = async_sessionmaker(bind=integration_engine, class_=AsyncSession, expire_on_commit=False)
       - Store original: original_factory = executor_module.AsyncSessionLocal
       - executor_module.AsyncSessionLocal = TestSession
       - Define async def override_get_db(): async with TestSession() as s: yield s
       - app.dependency_overrides[get_db] = override_get_db
       - async with AsyncClient(transport=ASGITransport(app=app), base_url="http://test", headers={"X-API-Key": INT_API_KEY}) as ac: yield ac
       - Teardown: app.dependency_overrides.clear(); executor_module.AsyncSessionLocal = original_factory

    5. Helper `_wait_for_terminal(client, run_id, max_iters=20, sleep_s=0.1)`:
       - Polls GET /runs/{run_id} up to max_iters times with asyncio.sleep(sleep_s)
       - Returns the response JSON when status is in TERMINAL_STATES
       - Raises AssertionError if terminal state not reached

    6. Test `test_full_workflow_happy_path(integration_client)`:
       - Register workflow: POST /workflows with name="int-happy", steps=[{name="step-1", execute_url="http://mock-svc/step1"}, {name="step-2", execute_url="http://mock-svc/step2"}]
       - Assert 201
       - async with respx.mock(assert_all_called=False) as mock:
           mock.post("http://mock-svc/step1").mock(return_value=httpx.Response(200))
           mock.post("http://mock-svc/step2").mock(return_value=httpx.Response(200))
           r = await integration_client.post(f"/workflows/int-happy/runs", json={})
           assert r.status_code == 202
           run_id = r.json()["run_id"]
           run_data = await _wait_for_terminal(integration_client, run_id)
       - assert run_data["status"] == "COMPLETED"
       - steps_r = await integration_client.get(f"/runs/{run_id}/steps"); assert steps_r.status_code == 200
       - steps = steps_r.json(); assert len(steps) == 2
       - assert all(s["status"] == "COMPLETED" for s in steps)

    7. Test `test_compensation_triggered_on_step_failure(integration_client)`:
       - Register workflow: POST /workflows with name="int-comp-fail", steps=[
           {name="step-1", execute_url="http://mock-svc/s1", compensate_url="http://mock-svc/comp1"},
           {name="step-2", execute_url="http://mock-svc/s2", compensate_url="http://mock-svc/comp2"}
         ]
       - async with respx.mock(assert_all_called=False) as mock:
           mock.post("http://mock-svc/s1").mock(return_value=httpx.Response(200))
           mock.post("http://mock-svc/s2").mock(return_value=httpx.Response(500))
           mock.post("http://mock-svc/comp1").mock(return_value=httpx.Response(200))
           mock.post("http://mock-svc/comp2").mock(return_value=httpx.Response(200))
           r = await integration_client.post("/workflows/int-comp-fail/runs", json={})
           assert r.status_code == 202
           run_id = r.json()["run_id"]
           run_data = await _wait_for_terminal(integration_client, run_id)
       - assert run_data["status"] in {"COMPENSATED", "COMPENSATION_FAILED"}
       - steps_r = await integration_client.get(f"/runs/{run_id}/steps")
       - steps = {s["step_name"]: s for s in steps_r.json()}
       - assert steps["step-1"]["compensation_status"] is not None  # was compensated
       - assert steps["step-2"]["status"] == "FAILED"

    8. Test `test_compensation_triggered_on_timeout(integration_client)`:
       - Register workflow: POST /workflows with name="int-comp-timeout", steps=[
           {name="step-1", execute_url="http://mock-svc/t1", compensate_url="http://mock-svc/tcomp1"},
           {name="step-2", execute_url="http://mock-svc/t2", compensate_url="http://mock-svc/tcomp2", timeout_seconds=1}
         ]
       - async with respx.mock(assert_all_called=False) as mock:
           mock.post("http://mock-svc/t1").mock(return_value=httpx.Response(200))
           mock.post("http://mock-svc/t2").mock(side_effect=httpx.TimeoutException("timeout"))
           mock.post("http://mock-svc/tcomp1").mock(return_value=httpx.Response(200))
           r = await integration_client.post("/workflows/int-comp-timeout/runs", json={})
           assert r.status_code == 202
           run_id = r.json()["run_id"]
           run_data = await _wait_for_terminal(integration_client, run_id)
       - assert run_data["status"] in {"COMPENSATED", "COMPENSATION_FAILED", "FAILED"}
       - steps_r = await integration_client.get(f"/runs/{run_id}/steps")
       - steps = {s["step_name"]: s for s in steps_r.json()}
       - assert steps["step-1"]["compensation_status"] is not None
