<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test process → real SQLite file | Integration tests write to NamedTemporaryFile; cleanup required |
| respx → httpx | respx intercepts all httpx.AsyncClient calls within mock scope |
| docker-compose → named volume | Container writes to db_data volume; data persists across restarts |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03-01 | Information Disclosure | SQLite temp file left on disk after test failure | mitigate | integration_engine fixture teardown calls os.unlink in finally block; engine.dispose() before unlink |
| T-04-03-02 | Tampering | Mutable global state (os.environ["API_KEY"]) in test module | accept | Test isolation: set at module level before app imports; get_settings.cache_clear() in fixture; test-only concern |
| T-04-03-03 | Elevation of Privilege | docker-compose runs container as root | accept | Interview scope; production hardening note: add USER appuser in Dockerfile |
| T-04-03-04 | Denial of Service | polling loop in _wait_for_terminal can block pytest | mitigate | max_iters*sleep_s ceiling at 10 seconds; if executor deadlocks, test fails with AssertionError rather than hanging indefinitely |
| T-04-SC | Tampering | No new packages installed in this plan | accept | No pip install; all packages from pyproject.toml already installed |
</threat_model>
